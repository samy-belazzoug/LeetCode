## How Am I organized

In LeetCode, there is 3 difficulty.
So, I use 1 language per difficulty : 

- Easy : Rust
- Medium : C / C++
- Hard : Python

At the start, I wanted to use Rust to do all the exercices, 
but I don't think its worth it. So, to discover the language, I do all 
the easy exercices in Rust.

As I kinda know well C and C++, so I can use these languages to do the Medium exercices.

Then, to do the Hard exercices, I will surely use Python. This is the language that can allow me
to focus the most on the exercice itself and not the syntax and every properties.
I can consider using C or Rust to do the least accepted exercices (Acceptance <= 15%) just to flex.
